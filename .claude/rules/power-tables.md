# Power tables

- `grisupow.hpp`, `schubfachpow.hpp`, `eisellemirepow.hpp` are generated by `tools/{grisupowgen,schubfachpowgen,eisellemirepowgen}` (ranges `-l`/`-u` in each tool README). Never hand-edit entries.
- The tools output a standalone header (`powers[]`, `MIN_EXPONENT`): paste the entries into the existing `dconv::details` table, keep its declaration as is (name, element type, `alignas` where present).
- Lookup offsets must match the range: `mk + 343` (`grisu.hpp`), `exponent + 342` (`eisellemire.hpp`), `292 - k` (`schubfach.hpp`).
- Tool changes: update its README.

# AGENTS.md

**dconv**: header-only C++20 double ⇄ string library (`dconv/include/dconv/`), used by join. Tests in `dconv/tests/`, table generators in `tools/`.

## Build and test

Presets `gcc|clang` x `debug|release|asan` (debug = coverage), trees in `build/<compiler>/<kind>`. `-Werror` is on.

```bash
cmake --preset gcc-debug && cmake --build --preset gcc-debug && ctest --preset gcc-debug
```

## Architecture

- **dtoa**: `dconv::dtoa` -> `schubfach::dtoa`. Each algorithm (`schubfach`, `grisu`, `grisu2`, `grisu3`) has `generate (buffer, length, k, value)`; the Grisu family renders it through the `grisu.hpp` driver and `details::prettify`, while `schubfach::dtoa` calls `shortest` then `details::format`; `grisu3` falls back to `std::to_chars`.
- **atod**: all overloads go through `details::atod<Probe>`. `StringProbe` seeks back to re-parse > 19 digits; `StreamProbe` never rewinds, so they go to `atodLong` (Eisel-Lemire bracketing, `strtod` only on disagreement). `Errc::NotDouble` reports 64-bit integers.
- **Power tables** (`*pow.hpp`): generated by `tools/*powgen`.

## Agent files

Skills in `.agents/skills/<name>/SKILL.md`: compile, test, coverage, conformance, performance, add-gtest, gen-tables, create-pr, release; `<scratchpad>` in them is a temporary directory outside the repository. Run `clang-format` (CI uses 19) on changed C++ files.

Changes to `AGENTS.md` and `.agents/` keep them tool-agnostic and short; `.claude/` is Claude Code only.

## Definition of done

- **Dev loop**: `gcc-debug`, the relevant test only.
- **Closing** (before asking to commit), gcc and clang: scope limited to the request; tests added; `debug`, `release`, `asan` pass; `coverage` not degraded; if conversion code changed, `conformance` and `performance` not degraded; `README.md` updated if the API or behaviour changes, else say none needed.

Report what ran; never call a partial pass done. A missing tool or wrong version: ask before installing (`sudo` if justified), else give the command with the `! ` prefix, and report the item **not verified**.

## Working agreements

- English for code, comments, commits, PRs, docs and branches.

- Ask before each branch, commit, push and PR (skill `create-pr`). Never force-push, push to `main` or merge.
